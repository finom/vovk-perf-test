## Overhead Performance Measurements for Vovk.ts

This repository contains tests measuring the performance overhead introduced by using [Vovk.ts](https://vovk.dev/) as a back-end framework for [Next.js](https://nextjs.org/) applications. For detailed information, please refer to the [performance testing article](https://vovk.dev/performance).

```sh npm2yarn
npm run perf-test
```
